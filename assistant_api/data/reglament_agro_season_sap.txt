Регламент заведения и экономического сопровождения агросезонов в SAP1. Общие положения  Агросезон представляет собой совокупность технологических операций по выращиванию культур в рамках планового периода.2. Заведение агросезона  В системе SAP создается агросезон с указанием:- дочернего общества;- культуры;- полей;- планируемых объемов работ;- бюджета.3. Формирование технологической карты  Для каждой культуры формируется технологическая карта, включающая:- перечень операций;- нормы расхода ресурсов;- сроки выполнения.4. Экономическое сопровождение  Экономист выполняет:- расчет плановой себестоимости;- контроль фактических затрат;- анализ отклонений.5. Контроль исполнения  Проводится регулярный анализ:- выполнения агросроков;- использования техники;- отклонений по затратам.6. Корректировки  Изменения в агросезоне допускаются только через:- служебные записки;- корректировку технологических карт;- пересчет норм.7. Отчетность  По итогам агросезона формируется отчет:- план/факт;- анализ эффективности;- рекомендации на следующий период.
