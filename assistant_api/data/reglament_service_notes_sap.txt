Регламент согласования служебных записок в системе SAP1. Общие положения  Служебные записки используются для согласования изменений в производственной программе и технологических операциях. Все изменения должны быть оформлены и согласованы до их фактического выполнения.2. Основания для создания служебной записки  Служебная записка создается в следующих случаях:- замена компонентов (например, удобрений, средств защиты растений);- замена агрооперации;- корректировка технологической карты;- создание сцепок техники;- создание внепланового заказа.3. Порядок создания  Инициатор оформляет служебную записку в системе SAP с указанием:- поля (участка);- культуры;- причины изменения;- описания изменений;- даты начала работ.4. Согласование  Служебная записка проходит следующие этапы согласования:- агроном;- руководитель подразделения;- экономист;- главный агроном (при необходимости).5. Особые условия  Без утвержденной служебной записки выполнение работ запрещено.  Все изменения фиксируются в системе SAP и подлежат последующему анализу.6. Ответственность  Ответственность за корректность данных несет инициатор записки.
